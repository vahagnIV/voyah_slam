# Global BA After Loop Correction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After every loop correction, a GlobalBA thread with its own map replica runs ORB-SLAM3's global BA. The Mapper then merges the result into the live map and publishes it as one transaction at the next epoch.

**Architecture:**
- **GlobalBA thread.** A new `global_ba::GlobalBundleAdjuster<FE>` mirrors the LoopCloser:
  - it is an `EventNode` with an inbox, a `WorkerThread`, and a `MapReplica` fed by the Mapper's `MapTransaction`s from the start;
  - a transaction that adds a loop edge triggers a run;
  - the run calls the existing `optimization::BundleAdjust` on the whole replica and publishes `GlobalBAFinished`.
- **Mapper merge** (new file `mapper_global_ba.cpp`):
  - it rejects stale results by map id and epoch;
  - it propagates the result to Frames and points created since, through the spanning tree and the points' reference Frames;
  - it publishes one `MapTransaction` at epoch + 1.
- **Tracker.** It follows through the existing epoch path; no Tracker code changes.

**Tech Stack:** C++20, Eigen, g2o (PRIVATE in algs), GoogleTest, CMake/Conan 2.

**Spec:** `docs/superpowers/specs/2026-10-10-global-ba-design.md`

## Global Constraints

- No locks on map data. Threads communicate only via events, and each thread owns its map replica.
- The Mapper is the only map writer. GlobalBA never mutates map objects.
- `GlobalBAFinished` carries plain data only: ids, poses and positions, with no pointers into map objects.
- With loop closing off (the default), behaviour is exactly as on master. No GlobalBA object is created.
- ORB-SLAM3 `GlobalBundleAdjustemnt(map, 10, &stop, loop_kf, bRobust = false)`:
  - one plain stage of `iterations` (10);
  - no robust kernel and no outlier removal;
  - residuals in raw pixels through `geometry::Camera`.
- Gauge: the map's first Frame is fixed, or the oldest surviving Frame if the first was culled. Mono poses are SE3, with no scale variable.
- Google style naming, the `out_` prefix for non-const reference params. DESIGN.md, TODO.md and ROADMAP.md are kept current.
- Statistical and synthetic tests use fixed seeds or deterministic scenes with margin. Never hand-pick a seed.
- Build and test commands are in CLAUDE.md. `check_all` runs at the end of every task, plus the clang-18/libc++ header check on changed headers.
- Known pre-existing flakes (TODO): `SlamTest.StereoRelocalizesAfterBlackout`, `SlamTest.MonoRelocalizesAfterBlackout`, `SlamTest.DuplicatesFusedInLongSequence`.

## Review Focus

1. **A Frame created after N whose parent was re-parented by culling after N.** Expected: it follows its current parent's correction. There is no dangling parent and no uncorrected Frame. Test: Task 3, `MapperGlobalBaTest.FollowsReparentedChain`.
2. **A new point whose reference Frame is itself new (created after N).** Expected: it moves with that Frame's propagated correction. Test: Task 3, `MapperGlobalBaTest.NewPointFollowsNewReferenceFrame`.
3. **The map's first Frame was culled.** Expected: the oldest surviving Frame is fixed and the optimization stays well posed. Test: Task 1, `GlobalBaProblemTest.FixesOldestSurvivingFrame`.
4. **Shutdown while a long global BA runs.** Expected: `Stop()` interrupts the BA promptly and nothing is published. Test: Task 2, `GlobalBundleAdjusterTest.StopInterruptsRunningBa`.
5. **The result pool is exhausted** (the Mapper is behind). Expected: the result is dropped with a log and a counter, with no abort; the next correction's run publishes normally. Test: Task 2, `GlobalBundleAdjusterTest.DropsResultWhenPoolExhausted`.

  ```cpp
  // events/global_ba_finished.h — mirror LoopDetected (Recyclable, ThreadSafePolicy, Reset()).
  struct GlobalBAFinished : Event, memory::Recyclable<GlobalBAFinished, memory::ThreadSafePolicy> {
      uint32_t map_epoch = 0;                                                  // N; Event::map_id is the map
      std::vector<std::pair<map::FrameId, geometry::RigidTransformation>> frame_poses;   // T_cw
      std::vector<std::pair<map::MapPointId, geometry::TPoint3DF>> point_positions;      // world
  };
  // global_ba/global_ba.h, namespace voyahslam::global_ba
  struct GlobalBaOptions {
      bool enabled = true;              // takes effect only when loop closing is on
      int iterations = 10;              // ORB-SLAM3 GlobalBundleAdjustemnt
      size_t max_events_in_flight = 2;  // GlobalBAFinished pool
      double sigma_px = 1.0;            // observation sigma at level 0 (as MapperOptions::fuse)
      double level_scale = 1.2;
  };
  struct GlobalBaSolution {
      std::vector<std::pair<map::FrameId, geometry::RigidTransformation>> frame_poses;
      std::vector<std::pair<map::MapPointId, geometry::TPoint3DF>> point_positions;
      map::FrameId fixed_frame{};
  };
  // Every Frame and every alive point with >= 1 observation; one plain BA stage. nullopt if
  // interrupted (should_stop), on an empty map, or on a non-finite result.
  template <typename TFeatureExtractor>
  std::optional<GlobalBaSolution> RunGlobalBa(const tracking::MapReplica<TFeatureExtractor>& replica,
                                              const GlobalBaOptions& options,
                                              const std::function<bool()>& should_stop);
  ```

  - `right_x` for stereo-matched features.

### Task 2: the `GlobalBundleAdjuster` component

**Files:**
- Create:
  - the component: `libs/slam/include/voyahslam/global_ba/global_bundle_adjuster.h`, `libs/slam/src/global_ba/global_bundle_adjuster.cpp`
  - test: `libs/slam/tests/global_ba/global_bundle_adjuster_test.cpp`

**Interfaces:**
- Consumes: Task 1 `RunGlobalBa`, `GlobalBaOptions`, `GlobalBAFinished`.
- Produces:
  ```cpp
  template <typename TFeatureExtractor>
  class GlobalBundleAdjuster : public events::EventNode {
  public:
      explicit GlobalBundleAdjuster(GlobalBaOptions options = {});
      ~GlobalBundleAdjuster();
      void Start();
      void Stop();                       // interrupts a running BA (should_stop sees stopping)
      [[nodiscard]] bool ProcessPending(); // tests drive it synchronously, as LoopCloser's
      [[nodiscard]] const tracking::MapReplica<TFeatureExtractor>& replica() const;
      [[nodiscard]] size_t num_runs_started() const;
      [[nodiscard]] size_t num_runs_interrupted() const;
      [[nodiscard]] size_t num_results_dropped() const;   // pool exhausted
      void set_run_hook(std::function<void()> hook);      // tests: called before each run
  };
  ```
- **Mirror `loop_closing::LoopCloser`** (loop_closer.h and .cpp): the inbox listener, the replica, ignoring old maps, clearing on `new_map`/a newer map id, the `WorkerThread` as the last member, and the `ObjectPool` with `TryCreate`.
- **`ProcessPending`**:
  1. Drain the inbox, applying every transaction to the replica.
  2. Remember a pending run if an applied transaction of the current map has non-empty `added_loop_edges`. A new map clears the pending run.
  3. After the drain, if a run is pending, run `RunGlobalBa` once at the replica's epoch.
  4. Publish `GlobalBAFinished` (map id, epoch, solution) unless interrupted, with `priority = true` so a running local BA in the Mapper yields to it.
- **`should_stop`** returns true if `Stop()` was requested, or if the inbox holds a waiting event (peek without consuming) that is either:
  - a `MapTransaction` with a larger epoch and a new loop edge, or
  - a new map.

  If peeking at a specific waiting event isn't supported by the inbox, rule the cheapest option: for example, stop on any waiting `MapTransaction` with `new_map` or with `map_epoch` > the run's epoch. Document the choice.

### Task 3: the Mapper merge

**Files:**
- Create: `libs/slam/src/mapping/mapper_global_ba.cpp`
- Modify: `libs/slam/include/voyahslam/mapping/mapper.h`, `libs/slam/src/mapping/mapper.cpp` (dispatch `GlobalBAFinished`)
- Test: `libs/slam/tests/mapping/mapper_test.cpp` (suite `MapperGlobalBaTest`)

**Interfaces:**
- Consumes: Task 1 `GlobalBAFinished`; the Mapper's spanning tree (`parent`/`children`), the point references, `map_epoch_`, and the transaction building used by `mapper_loop.cpp` (`ResetTransactionScratch()` and the publish path).
- Produces:
  ```cpp
  // Mapper (private): rejection, then MergeGlobalBa; counters for tests.
  void OnGlobalBaFinished(const events::GlobalBAFinished& event);
  // Reusable (step 5): applies optimized poses/positions and propagates to the rest.
  void MergeGlobalBa(const std::vector<std::pair<map::FrameId, geometry::RigidTransformation>>& frame_poses,
                     const std::vector<std::pair<map::MapPointId, geometry::TPoint3DF>>& point_positions);
  [[nodiscard]] size_t num_global_ba_merges() const;
  [[nodiscard]] size_t num_global_ba_rejected() const;
  ```
- **Rejection.** Reject when `event.map_id` ≠ the current map, or `event.map_epoch` ≠ `map_epoch_`.
- **Frames.** A breadth-first walk from the root Frame(s), visiting parents before children:
  - in the result: take the optimized pose;
  - otherwise, with a corrected parent: `T_new = T_cur · T_parent,cur⁻¹ · T_parent,new`, where `T_parent,cur` is the parent's pose before the merge;
  - culled Frames are not in the tree, so nothing is visited for them.
- **Points.**
  - In the result and alive: take the optimized position.
  - Not in the result, alive, with a corrected reference Frame: `X_new = T_ref,new⁻¹ · T_ref,cur · X`.
  - Otherwise unchanged.
- **Publish.** One transaction with `updated_poses` and the updated point positions, at `map_epoch_ + 1`, with no loop edges. Check the field name the correction uses for point positions in `mapper_loop.cpp` and reuse it.
- **During a merge.** A local BA running when the result arrives is interrupted the same way a `LoopDetected` interrupts it: Task 2 publishes `GlobalBAFinished` with `priority = true`.
