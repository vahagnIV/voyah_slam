# Tracking Against the Map (Sub-project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stub `PoseEstimator` with ORB-SLAM3-style frame-to-map tracking, for mono and stereo. The parts are a Tracker map replica, projection matching, and motion-only g2o pose optimization.

**Architecture:** Three new testable units:
- `tracking::MapReplica`, built from Mapper events.
- `features::` projection matching: from the last frame, and from the local map.
- `optimization::OptimizePose`: unary g2o edges, mono and stereo, with g2o kept private.

The Tracker composes them per frame: a motion model, then a zero-motion fallback, then the local map. It publishes real `PositionUpdated` events, or `TrackingLost`.

**Tech Stack:** C++20, Eigen, g2o 20241228 (PRIVATE), GoogleTest, Conan 2/CMake.

**Spec:** `docs/superpowers/specs/2026-10-05-tracking-design.md`

## Global Constraints

- Branch `feat/tracking`. Commit per task. Never merge or push.
- Google style:
  - `PascalCase` types and functions;
  - `snake_case` variables and `snake_case_` members;
  - `out_` prefix for non-const reference parameters.
- No g2o, OpenCV or Pangolin type in any public header (`include/`). g2o is PRIVATE.
- Lock-free design:
  - The Tracker never mutates map objects. The replica is the Tracker's private copy, built only from events.
  - Only the Tracker thread touches the replica.
- Poses are `T_cw` (world → camera), with `T_ab`: p_a = T_ab · p_b. `StereoRig::T_rl` maps left → right.
- Matching works in undistorted pixel coordinates (`K · Xc/Xc.z`, the space of `measurement.points()`). Optimization works in normalized coordinates (z = 1).
- Build and test:
  - Full: `cmake --build cmake-build-debug/build/Debug -j8 && ctest --test-dir cmake-build-debug/build/Debug -j8 --timeout 120`
  - Focused: `cmake-build-debug/build/Debug/tests/voyahslam_tests --gtest_filter='<Suite>*'`
  - The Release tree `build/build/Release` must build too.
  - All existing tests stay green (361 on master), except the stub-era Tracker and `PoseEstimator` tests that Task 5 deliberately rewrites or deletes.
- Every new or changed header passes `clang++-18 -std=c++20 -stdlib=libc++ -fsyntax-only`, using the flags from `voyahslam_tests`' `flags.make`.

## Review Focus

1. **A stereo measurement whose features have no stereo match.** Every observation has `right` = nullopt while `T_rl` is set. Expected: `OptimizePose` uses mono edges only and behaves exactly like mono. Test in Task 2: `StereoWithoutRightObservationsBehavesAsMono`.
2. **A map point removed (`MapPointsRemoved`) that is still in the last frame's matches.** Expected: the matcher skips dead points, and nothing reads stale data. Test in Task 3: `SkipsDeadPoints`.
3. **Two current features competing for the same map point, and one feature competing for two points.** Expected: one-to-one matching, where the closer descriptor wins. Test in Task 3: `OneToOneClaims`.
4. **A newer map arriving while Tracking**, after loss and re-initialization. Expected: the replica is cleared, and `last_frame_` and velocity are reset to the new `MapCreated` keyframe. No matches into the old map survive. Test in Task 5: `NewMapResetsTrackingState`.
5. **Every replica point behind the camera or out of view (a teleported frame).** Expected: `TrackingLost`, with no crash and no NaN pose published. Test in Task 5: `TeleportedFrameIsLost`.

  namespace voyahslam::tracking {
  struct PointReference { map::FrameId keyframe; Eigen::Index feature; int level; double distance; };
  template <typename FE> struct ReplicaKeyFrame {
      map::FrameId id; geometry::RigidTransformation T_cw;
      features::TMeasurement<FE> measurement;

### Task 2: Right-camera Jacobian and `optimization::OptimizePose`

**Files:**
- Modify: `src/optimization/projection.h` (add the right-camera helpers)
- Create: `include/voyahslam/optimization/pose_optimization.h`, `src/optimization/pose_optimization.cpp` (add it to `src/CMakeLists.txt`)
- Test: `tests/optimization/projection_test.cpp` (extend), `tests/optimization/pose_optimization_test.cpp` (add it to CMake)

**Interfaces:**
- Consumes: `ProjectNormalized`, `ProjectionJacobians` (existing).
- Produces, in `src/optimization/projection.h`:
  ```cpp
  // π(T_rl · T_cw · X) and its Jacobian w.r.t. the left perturbation of T_cw (ω then υ, g2o order).
  geometry::TPoint2DF ProjectNormalizedRight(const RigidTransformation& T_cw, const RigidTransformation& T_rl, const TPoint3DF& X);
  void ProjectionJacobianRightPose(const RigidTransformation& T_cw, const RigidTransformation& T_rl, const TPoint3DF& X,
                                   Eigen::Matrix<precision_t, 2, 6>& out_pose);
  ```
  Derivation: with `Xc = T_cw·X` and `Xr = T_rl·Xc`, the Jacobian is `∂π(Xr) · R_rl · [−[Xc]× | I]`.
- Produces: the spec §3 types and `OptimizePose`, verbatim. Unary mono and stereo edges are defined only in the `.cpp`. The schedule follows spec §3: 4 rounds × 10 iterations, re-classify after each round, Huber in rounds 0–1, no kernel from round 2. `success = num_inliers ≥ 3 && finite`. Invalid input (non-finite values, sigma ≤ 0, or a `right` value without `T_rl`) gives `success = false`.

  - `PoseOptimizationTest.StereoWithoutRightObservationsBehavesAsMono`: with `T_rl` set but every `right` nullopt, the result equals the mono run (1e-9).
  - `PoseOptimizationTest.InvalidInputFails`: empty observations; NaN; sigma 0; `right` set without `T_rl`. All give `success == false`.
  - `PoseOptimizationTest.TooFewInliersFails`: 2 observations → false.

### Task 3: Projection matching

**Files:**
- Create: `include/voyahslam/features/projection_matcher.h` (header-only template), `tests/features/projection_matcher_test.cpp` (add it to CMake)

**Interfaces:**
- Consumes: `tracking::MapReplica` (Task 1), `features::FeatureGrid`, `levels()`, `angles()`, `TFeatureExtractor::Distance`. - Produces (namespace `voyahslam::features`; spec §2 verbatim):
  ```cpp
  struct ProjectionMatcherOptions { double max_distance_last = 100.0; double max_distance_map = 100.0; double nn_ratio_map = 0.8;
      bool check_orientation = true; size_t histogram_bins = 12; double level_scale = 1.2; int max_level = 7; double max_ray_angle_deg = 85.0; };
  // matches[i] = MapPointId value of current feature i, or -1.
  template <typename FE> std::vector<int64_t> SearchFromLastFrame(
      const TMonocularMeasurement<FE>& current, const geometry::RigidTransformation& T_cw,
      const TMonocularMeasurement<FE>& last, const std::vector<int64_t>& last_matches,
      const tracking::MapReplica<FE>& replica, double radius_px, const ProjectionMatcherOptions& options);
  template <typename FE> size_t SearchFromLocalMap(
      const TMonocularMeasurement<FE>& current, const geometry::RigidTransformation& T_cw,
      const tracking::MapReplica<FE>& replica, std::vector<int64_t>& out_matches, double th,
      const ProjectionMatcherOptions& options);
  ```
  Binocular measurements pass `left()`. Projection uses `current.K()`. The out-of-bounds test uses the current measurement's point bounding box. The ray-angle test is `Xc.z / ‖Xc‖ ≥ cos(max_ray_angle_deg)`.
